    GitHub Coding Agent

    This is a separate, token-authorized tool—not the normal chat. It can inspect the selected repository, ask FreeApp AI to prepare code changes, commit them to a new branch, open a pull request, and report GitHub Actions checks. The normal chat cannot access your private repository or use this token.

    Use a fine-grained token limited to the chosen repository with Contents: Read and write, Pull requests: Read and write, and Actions: Read (to inspect build/check results). The token is sent directly from this screen to GitHub over HTTPS; it is not sent to the AI inference endpoint and is not saved by this page. Clear it when finished. Never paste a password or token into the normal AI chat.

    No repository changes are made until you run a coding task. Changes are committed to a new branch and submitted as a pull request—not directly to the default branch. The agent does not merge, deploy, or publish releases. Build/test results are reported only when GitHub Actions returns evidence.

    Phone Control (Android)

    FreeApp AI can open supported apps and perform visible screen actions after you enable its accessibility service. Enable it yourself in Android settings and keep the phone unlocked while actions run.

    For screen actions, enter one action per line. Supported: open Gmail/Settings/Chrome/Play Store/Files; tap: visible label; type: ordinary text into the currently focused field; scroll up/down; back; home. Actions are sent to the current screen, so watch the phone. FreeApp AI will not type passwords, one-time codes, security codes or card details. You must sign in yourself and approve sending emails, payments, deleting data, security changes, or other consequential actions. System updates still require Android's own confirmation.

    Phone control is available only in the Android app after you enable the service.
